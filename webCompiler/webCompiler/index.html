TraceLang reference

          
TraceLang is a small language inspired by Python. Blocks are shown by indentation, not braces, and there are no semicolons.


          
Program structure

          
Every program starts with start and ends with end. Indent blocks with 4 spaces. Comments start with #.


start

age: int = 20
name: string = "Alina"
show name
show age

end


          
Types

          
int (whole numbers), float (decimal numbers such as 85.5), string (text in double quotes) and bool (true or false). An int value can be used where a float is needed.


          
Variables


age: int = 20          # declare with a value
total: int            # declare without a value
total = age + 5       # assign a new value (the type must match)

          
Do not use let. A variable must get a value before it is used.


          
Input and output


write age: int        # declare and read an int from the input
write name            # read into an existing variable
show "Hello"          # output a text
show age + 10         # output a value

          
write reads one line of input for each use. Supported types: int, float, bool, string.


          
Operators

          

            
KindOperators

            
Arithmetic+ - * / %

            
Relational== != < > <= >=

            
Logicaland or not

          

          
Precedence, from lowest to highest: or, and, not, comparisons, + -, * / %, unary -. Use parentheses to change the order. Comparisons cannot be chained: write a < b and b < c.

          
% works on int values only. / between two ints gives an int (the fraction is cut off). Division by a zero literal is an error.


          
If, elif and else


if marks >= 50:
    show "Pass"
    if marks >= 80:
        show "Distinction"
elif marks >= 40:
    show "Weak pass"
else:
    show "Fail"

          
The condition must be bool. Conditions can be nested.


          
Loops


i: int = 1
while i <= 5:
    show i
    i = i + 1

for k in 1 to 3:      # k goes 1, 2, 3 (both ends included)
    show k

          
The loop variable of a for loop cannot be changed inside the loop.


          
Functions


function add(a: int, b: int) -> int:
    result: int = a + b
    return result

function greet(name: string):
    show name

total: int = add(10, 20)
greet("Alina")

          
Functions are defined at the top level of the program. A function with -> type must end with return value of that type. A function without a return type uses return with no value, or no return at all.


          
Scope

          
A variable exists only in the block where it is declared, and in the blocks inside it. A name can be declared again in an inner block. Functions can read the global variables (the ones declared at the top level), but they cannot change them. Pass values in as parameters and return the result.


          
Common errors

          
    
            
  • Undeclared name: declare the variable or function before you use it.
    • 
            
  • Type error: both sides of an assignment, comparison or operator must have compatible types.
    • 
            
  • Used before a value: give the variable a value first.
    • 
            
  • No string joining: + cannot join text. Use separate show lines.
    • 
            
  • Indentation error: each block must be indented the same way, and end must be at column 1.
    •
